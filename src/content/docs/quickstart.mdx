## 1. Sign up

Go to [wirelog.ai](https://wirelog.ai) and sign in with GitHub. A default organization is created automatically.

## 2. Create a project

From the dashboard, create a new project. You get two API keys:

| Key | Prefix | Use |
|-----|--------|-----|
| Public key | `pk_...` | Client-safe. Track events from browsers. |
| Secret key | `sk_...` | Server-side. Track, query, and admin. |

You can copy either key from the project settings page at any time.

## 3. Copy the script tag

Your project page shows the script tag with your public key already filled in. Copy it.

## 4. Add it to your site

Paste the script tag into your HTML, before `</head>` or at the end of `<body>`:

```html
<script
  src="https://cdn.wirelog.ai/public/wirelog.js"
  data-key="pk_YOUR_PUBLIC_KEY"
></script>
```

That's it. The script tag automatically tracks:
- **Page views** on every page load and SPA navigation
- **Sessions** with 30-minute inactivity timeout
- **Device identity** via localStorage (persistent across visits)
- **UTM attribution** (`utm_source`, `utm_medium`, `utm_campaign`, etc.)
- **Referrer, geo, browser, OS, viewport** -- all auto-captured

## 5. Query your page views

Once you have some traffic, try these queries from your project's query tool or via the API. Every query below works with zero custom event tracking.

### What's getting traffic?

```
page_view | last 7d | count by _path | top 20
```

### Daily visitors

```
page_view | last 7d | unique distinct_id by day
```

### Where are visitors coming from?

```
sessions | last 30d | count by session.utm_source
```

### Top landing pages

```
sessions | last 30d | count by session.landing_path | top 20
```

### How do people navigate your site?

```
paths from page_view | last 30d | by _path
```

### Visitor retention

```
retention page_view | last 90d
```

These are just a few. See [Script Tag Queries](/guides/script-tag-queries) for the full set -- traffic, sessions, attribution, geo, devices, navigation paths, retention, and more.
</Aside>

## Going further

### Track custom events with the TypeScript client

The `wirelog` package shares identity with the script tag -- same `device_id`, same `user_id`, no conflicts.

```bash
npm install wirelog
```

```ts
import { wl } from "wirelog";

wl.init({ apiKey: "pk_YOUR_PUBLIC_KEY" });

wl.track({ event_type: "signup", event_properties: { plan: "free" } });

wl.identify({ user_id: "alice@acme.org", user_properties: { plan: "pro" } });
```

Full reference: [TypeScript Client](/tracking/typescript-client)
