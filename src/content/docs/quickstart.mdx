## 1. Sign up

Go to [wirelog.ai](https://wirelog.ai) and sign in with GitHub. A default organization is created automatically.

## 2. Create a project

From the dashboard, create a new project. You get two API keys:

| Key | Prefix | Use |
|-----|--------|-----|
| Public key | `pk_...` | Client-safe. Track events only. |
| Secret key | `sk_...` | Server-side only. Track + query + admin. |

Copy both. The secret key is shown once.

## 3. Add the script tag

Drop this into your HTML. One line -- you're tracking.

```html
<script
  src="https://cdn.wirelog.ai/public/wirelog.js"
  data-key="pk_YOUR_PUBLIC_KEY"
></script>
```

This immediately gives you:
- `page_view` events on every page load (and SPA navigation)
- Session management with 30-minute inactivity timeout
- Device identity via localStorage
- UTM attribution capture (`utm_source`, `utm_medium`, etc.)
- Referrer, geo, browser, viewport -- all auto-captured

<Aside type="tip">
See [Script Tag Queries](/guides/script-tag-queries) for the full set of queries that work immediately with just the script tag.
</Aside>

## 4. Install the TypeScript client

For custom events in your app, add the `wirelog` package. It shares identity with the script tag -- same `device_id`, same `user_id`, no conflicts.

```bash
npm install wirelog
```

```ts
import { wl } from "wirelog";

wl.init({ apiKey: "pk_YOUR_PUBLIC_KEY" });

// Track custom events
wl.track({ event_type: "signup", event_properties: { plan: "free" } });

// Identify a logged-in user (persists across script tag too)
wl.identify({ user_id: "alice@acme.org", user_properties: { plan: "pro" } });

// All subsequent track() calls include user_id automatically
wl.track({ event_type: "feature_used", event_properties: { feature: "export" } });
```

Browser `track()` calls are buffered (10 events or 2 seconds) and delivered via `sendBeacon` on page close.

## 5. Query your data

Queries use a pipe DSL and require a secret key (`sk_`) or an access token with `query` scope. The fastest way to try it:

```bash
$ curl -X POST https://api.wirelog.ai/query \
    -H "X-API-Key: sk_YOUR_SECRET_KEY" \
    -H "Content-Type: application/json" \
    -d '{"q": "* | last 1d | count by event_type", "format": "llm"}'
```

```markdown
## * | last 1d | count by event_type

| event_type | count |
|------------|-------|
| page_view  |    47 |
| signup     |     3 |
```

Or query from the TypeScript client (server-side):

```ts
import { WireLog } from "wirelog";

const client = new WireLog({ apiKey: "sk_YOUR_SECRET_KEY" });
const result = await client.query("page_view | last 7d | count by _path | top 10");
console.log(result);
```

Output formats: `llm` (Markdown, default), `json`, `csv`.

## 6. Set up identity

Bind a device to a known user so pre-login events get stitched to the same `distinct_id`. If you used `wl.identify()` in step 4, you're already set. For server-side or curl:

```bash
$ curl -X POST https://api.wirelog.ai/identify \
    -H "X-API-Key: pk_YOUR_PUBLIC_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "user_id": "alice@acme.org",
      "device_id": "dev_abc123",
      "user_properties": {"email": "alice@acme.org", "plan": "pro"}
    }'
```

```json
{"ok": true}
```
